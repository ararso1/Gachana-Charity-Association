# Gachana Charity Association

Django website for [Gachana Charity Association](https://www.gachanacharity.com) — a non-profit based in Dire Dawa, Ethiopia.

## Documentation

**[Full functionality guide (start to end)](docs/FUNCTIONALITY.md)** — public site, member/staff/admin portals, donations, content management, URLs, and setup.

## Quick start

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Login: `/login/` · Admin dashboard: `/portal/admin/`
